# Changelog

## [0.0.8] - 2026-01-18

### Fixed
- Fixed missing opus headers in published package
- Added header copying to build-opus-android.sh script
- Ensures opus.h is included in npm package for JNI compilation

## [0.0.7] - 2026-01-15 (BROKEN - missing headers)

### Fixed
- Android native libraries now support 16 KB memory page sizes (Google Play requirement)
- Added linker flags for 16KB alignment to opus_encoder and lame_encoder shared libraries
- Ensures compatibility with Android devices using 16KB memory pages starting November 2025

### Changed
- All native library headers now generated by CI instead of tracked in git
- Added ios/Shims/ and android/src/main/cpp/include/ to .gitignore

### Technical Details
- Added `target_link_options` with `-Wl,-z,max-page-size=16384` to CMakeLists.txt
- Affects libopus_encoder.so and liblame_encoder.so across all architectures
- Required for Google Play Store submission targeting Android 15+
